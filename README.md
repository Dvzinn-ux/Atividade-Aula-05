# ⚔️ Ichigo Kurosaki - Bleach

## Sobre o projeto

Este projeto é um site desenvolvido em HTML sobre **Ichigo Kurosaki**, protagonista do anime e mangá *Bleach*.

O objetivo é apresentar informações sobre o personagem, seus poderes, sua família, suas transformações e os principais arcos da história.

## Conteúdo do site

-  Página inicial
-  Biografia de Ichigo
-  Poderes
-  Zangetsu
-  Bankai
-  Versão Hollow
-  Família
-  Arcos de Bleach
-  Citações
-  Formulário de mensagem

##  Tecnologias utilizadas

- HTML

O projeto foi desenvolvido utilizando apenas HTML.
